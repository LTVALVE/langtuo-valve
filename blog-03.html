Valve Selection for Vietnam/Indonesia Refinery Projects: Materials & Standards for High-Pressure, High-Temperature Service

📅 2026-10-13 👥 朗拓阀门技术团队 🔖 炼化项目 · 高压高温

随着越南、印尼持续推进炼化产能扩张（区域新增炼油能力约 120 万桶/日），一批常减压、催化裂化、加氢精制装置进入设备采购高峰。炼化装置用阀门长期处于 高温（200–550°C）、高压（Class 300–900）甚至含硫化氢的腐蚀性工况，对材料、密封与标准的要求远超通用工业阀门。本文为项目采购工程师梳理关键选型决策点。

1. 压力等级与温度工况 Pressure Class & Temperature

装置区域常见压力等级典型温度推荐阀型
常压蒸馏（CDU）Class 150–300≤ 370°C闸阀、球阀
加氢/催化裂化Class 600–900350–550°C闸阀、截止阀
蒸汽与锅炉给水Class 300–600≤ 450°C截止阀、止回阀
火炬与放空系统Class 150–300—球阀（防火型）

压力等级选择遵循 ASME B16.34 的温度-压力额定表：温度升高后同等 Class 允许压力下降，选型时必须对照"设计温度下的允许工作压力"，而非只看铭牌 Class。

2. 阀体材料选择 Body Material Selection

2.1 材料对照

材料适用温度典型工况
WCB（碳钢）-29 ~ 425°C油品、蒸汽一般管线
WC6 / WC9（铬钼钢）-29 ~ 595°C高温蒸汽、热油（常压/减压侧）
CF8 / CF8M（不锈钢）-196 ~ 425°C抗硫、耐蚀介质；湿H₂S工况
低温钢 LCB（-46°C）低温工况LPG 装置、冷剂系统

2.2 关键提示

  • 含 H₂S 工况须按 NACE MR0175/ISO 15156 评估材料抗硫化物应力开裂性能
  • 高温工况阀门密封面建议选择stellite 堆焊或整体硬质合金
  • 阀杆采用 17-4PH 或 Inconel 718 等耐蚀高强度合金
  • 要求供应商提供冲击试验报告与高温拉伸数据

3. 执行标准对照 Standard Reference Table

项目国际通用中国等效
工业阀门设计API 6D / ASME B16.34GB/T 12224
闸阀API 600 / API 603GB/T 12234
球阀API 608 / API 6DGB/T 12237
蝶阀API 609GB/T 12238
法兰连接ASME B16.5 / B16.47GB/T 9113 / HG/T 20592
压力测试API 598 / ISO 5208GB/T 13927

采购建议：合同明确写清"按 API 6D 设计 + API 598 测试"，并约定第三方检验（SGS/BV/TUV）见证压力与密封试验；中国等效标准仅作对比参考，避免混用。

4. 零泄漏密封等级 Zero-Leakage Requirements

  • 软密封球阀可达 ISO 5208 Rate A / 零泄漏（Class VI）
  • 金属密封阀门一般按 Rate B/C 验收，需项目方确认可接受泄漏量
  • 高空放、火炬管线首选 双截断泄放（DBB）球阀设计
  • 防火安全要求时选用 API 607 / ISO 10497 防火测试结构的阀门

5. 采购落地建议 Procurement Advice

越南、印尼项目对到货文件要求严（材质证明、压力测试报告、溯源证书常需公证翻译）。建议选择具备完整第三方检验经验与文件交付能力的中国供应商。朗拓阀门常备 WC6/WC9 高温阀与 CF8M 抗硫阀产线，支持 API 6D 设计与 SGS 第三方见证测试，深圳发货至胡志明、雅加达港约 7–14 天，可显著压缩项目采购周期。

As Vietnam and Indonesia continue expanding refining capacity (about 1.2 million bpd of new regional capacity), a wave of crude distillation, catalytic cracking and hydrotreating units has entered the equipment procurement peak. Refinery valves operate under long-term high temperature (200–550°C), high pressure (Class 300–900) and even corrosive hydrogen-sulfide service, with requirements for material, sealing and standards far beyond general-purpose industrial valves. This article maps the key selection decisions for project procurement engineers.

1. Pressure Class and Temperature Duty

Unit AreaCommon Pressure ClassTypical TemperatureRecommended Type
Crude distillation (CDU)Class 150–300≤ 370°CGate, ball
Hydrotreating / FCCClass 600–900350–550°CGate, globe
Steam and boiler feedwaterClass 300–600≤ 450°CGlobe, check
Flare and vent systemsClass 150–300—Ball (fire-safe)

Pressure class selection follows the ASME B16.34 pressure-temperature rating table: at higher temperatures the allowable working pressure of the same class drops, so always compare against the "allowable working pressure at design temperature" rather than the nameplate class alone.

2. Body Material Selection

2.1 Material Comparison

MaterialApplicable TemperatureTypical Service
WCB (carbon steel)-29 to 425°CGeneral oil and steam lines
WC6 / WC9 (Cr-Mo steel)-29 to 595°CHigh-temperature steam, hot oil (atmospheric/vacuum side)
CF8 / CF8M (stainless steel)-196 to 425°CSour and corrosive media; wet H2S service
Low-temp steel LCB (-46°C)Low-temperatureLPG units, refrigerant systems

2.2 Key Notes

  • For H2S service, evaluate sulfide stress cracking resistance per NACE MR0175 / ISO 15156
  • Seat surfaces for high temperature are recommended to use stellite overlay or solid hard-facing
  • Stems should use 17-4PH or Inconel 718 corrosion-resistant high-strength alloys
  • Require impact test reports and high-temperature tensile data from the supplier

3. Governing Standard Reference

ItemInternationalChinese Equivalent
Industrial valve designAPI 6D / ASME B16.34GB/T 12224
Gate valveAPI 600 / API 603GB/T 12234
Ball valveAPI 608 / API 6DGB/T 12237
Butterfly valveAPI 609GB/T 12238
Flange connectionASME B16.5 / B16.47GB/T 9113 / HG/T 20592
Pressure testingAPI 598 / ISO 5208GB/T 13927

Procurement advice: state clearly in the contract "designed to API 6D + tested to API 598" and arrange third-party witness (SGS/BV/TUV) of pressure and seat tests. Chinese equivalent standards are for reference only — avoid mixing them.

4. Zero-Leakage Sealing Levels

  • Soft-seated ball valves can reach ISO 5208 Rate A / zero leakage (Class VI)
  • Metal-seated valves are generally accepted at Rate B/C; confirm acceptable leakage with the project
  • For elevated vents and flare lines, prefer double-block-and-bleed (DBB) ball valves
  • When fire safety applies, specify API 607 / ISO 10497 fire-tested valve construction

5. Procurement Advice

Vietnamese and Indonesian projects are strict about shipping documents (material certifications, pressure test reports, traceability certificates, often requiring notarized translation). Choose a Chinese supplier with complete third-party inspection experience and document delivery capability.
